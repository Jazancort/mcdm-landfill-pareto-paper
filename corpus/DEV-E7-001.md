## Gate failure mode (2026-11-01) — separate from seed issue

**Symptom:** E7 final run (seed=42, correct) reported `nan%` for all G1 and G2 gates despite
data being correct (verified directly from CSV by `verify_e7_gates.py`).

**Cause:** The Athena Python environment uses pandas 3.x with `future.infer_string=True` by
default, which creates `StringDtype` columns when building a DataFrame from Python strings.
Boolean comparisons on `StringDtype` columns return `BooleanArray`; indexing a DataFrame with
a composite `BooleanArray` mask may produce an empty result in certain pandas 3.x versions
(regression, affects `(s == 'value') & ...` patterns, not `pd.DataFrame.query()`).

**Note:** The user flagged that plain `BooleanArray` indexing normally works. An alternative
cause is type mismatch at read time. The mechanism was not fully isolated; the fix below
is robust regardless.

**Fix (commit `1f9e08d`):**
1. `run_e7_kappa_sweep.py`: G1 and G2 filters changed to `dfk.query("agg=='saw' and ...")`.
2. `scripts/verify_e7_gates.py`: standalone gate verification using `.query()`.
3. G3 was never affected (uses `.nunique()`, not a boolean mask).

**Remaining action:** Replace `.query()` with explicit `astype(object)` coercion on the string
columns after `pd.DataFrame(all_records)`, and add `assert len(rows) > 0` guard in each gate
filter. This ensures the fix is robust to future pandas changes and makes filter failures
visible immediately rather than silently returning `nan%`. See gate fix TODO below.

**Two separate commits for the two problems:**
- `319c733` — seed fix (DATA_SHA guards, SEED_50 corrected in docstring)
- `1f9e08d` — gate fix (`.query()` + verify_e7_gates.py)

## Crossover point (correction to commit `1f9e08d`)

Commit `1f9e08d` message says "Reversal at kappa~150". This is wrong.

Linear interpolation between κ=100 (+9.3 pp) and κ=200 (−0.4 pp):
  κ* = 100 + 100 × 9.3 / (9.3 + 0.4) = 100 + 95.9 ≈ 196.

Log interpolation gives ≈194. The 95% CI bounds cross zero at approximately [170, 240].
The grid resolves nothing between κ=100 and κ=400; no sharp threshold can be stated.

Correct framing for §7.x: "the contrast decreases monotonically, is statistically equivalent
to zero at κ=200 (TOST δ=2.5 pp, p=\TOSTp), and changes sign for κ ≥ 400. The crossover
falls somewhere in (100, 400); the grid does not resolve it further."
