# DEV-E7-001: κ=50 gate G1 failed in E7 v1 due to wrong seed derivation

**Status:** Resolved in E7 v2 (run_e7_kappa_sweep.py, second run).

## Problem

E7 v1 (first run, 2026-10-30) used `seed = BASE_SEED + κ = 100 + 50 = 150` for κ=50.

The PRESPEC §2 specified that κ=50 reuse the existing seed. The existing seed for κ=50
is **seed=42**, identical to κ=200, because `mc_2cube_and_4thcell.py` creates a fresh
`np.random.default_rng(42)` for each α value in sequence:

```python
SEED   = 42
ALPHAS = [50, 200]
for alpha in ALPHAS:
    rng = np.random.default_rng(SEED)   # fresh per alpha
    ...
    w = rng.dirichlet(alpha * w_ahp)
```

So `W_k50 = np.random.default_rng(42).dirichlet(50 * w_ahp, size=500)` and
`W_k200 = np.random.default_rng(42).dirichlet(200 * w_ahp, size=500)` — same seed,
different concentration parameter.

## Fix in E7 v2

- Generated `results/e1/e1_weights_k50.npy` from `np.random.default_rng(42).dirichlet(50 * w_ahp, size=500)`.
- SHA-256: `e761c76d47bb7b6f949d116170fd900b8a87f4c356bf4a149f403a0f586060be`.
- Added `E1_SHA50` verification in `run_e7_kappa_sweep.py`.
- G1 κ=50 expected to reproduce all 16 cells to within 0.1 pp (exact replication).

## Consequence for reported E7 contrasts

The Agg_pooled3 contrast at κ=50 was +16.5 pp (v1) vs expected +20.4 pp (Tab.6).
After fix, it should reproduce ≈+20.4 pp. The other κ values (25, 100, 400, 1000)
are unaffected (independent seeds, not gate-checked values).
